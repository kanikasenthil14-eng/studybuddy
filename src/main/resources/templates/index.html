How Study Matching Works

The compatibility score is calculated using five criteria (maximum 100 points):

⏰ Compatible Study Time15 pts
📍 Same Preferred Location15 pts
📊 Compatible Skill Level10 pts

This is a rule-based compatibility estimate, not a scientifically validated prediction or machine-learning model.
